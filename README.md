# PANOPTR

Прототип системы компьютерного зрения для видеоконтроля железнодорожной инфраструктуры. Результаты предназначены для проверки специалистом; приложение не управляет поездом.

## Установка с чистого скачивания: Windows 10/11 x64

1. Python и команда `py` не требуются: установщик скачает проверенный Python 3.12 x64 отдельно в папку проекта. Нужны Windows x64 и интернет.
2. Скачайте ветку проекта целиком, распакуйте в доступную для записи папку. Не запускайте файлы внутри архива.
3. Запустите `00_Установить_среду.bat`. Нужен интернет: установщик создаёт новое изолированное окружение в `data/envs` и устанавливает зависимости, включая `opencv-python` (`cv2`). Он не удаляет папки в системном Python и не использует старый `runtime`.
4. Запустите `00_Скачать_модели.bat` (интернет, около 300 МБ). Скрипт скачивает 19 основных весов из зафиксированного коммита и проверяет размеры и Git blob hash. Существующие файлы он не перезаписывает. Если файл повреждён, сохраните его отдельно и повторите загрузку.
5. Запустите `05_Проверить_сборку.bat`, затем `01_Запустить_CPU.bat`. Выберите видео или камеры и запустите каналы в окне. Состояние проверки — `data/last_check.json`.

**Если cv2 перестал импортироваться:** закройте приложение и снова запустите `00_Установить_среду.bat`. Установщик скачает отдельный Python и создаст новую среду; старые файлы и системные библиотеки не удаляются. Переключение произойдёт только после успешной проверки импортов. Для установки требуется свободное место и интернет. GPU-версия PyTorch и совместимый драйвер NVIDIA настраиваются отдельно; стандартная установка не гарантирует CUDA.

## Другие команды

- `02_Запустить_GPU.bat` — запуск с выбором GPU; наличие CUDA проверяется отдельно.
- `03_Лаборатория_данных.bat`, `04_Карта_рейсов.bat`, `06_Полигон_и_финал.bat` — дополнительные модули.
- `07_Тесты_после_доработок.bat` — автоматические тесты; `08_Диагностика_камер.bat` — проверка камер; `09_Прогон_стресс_матрицы_ВСМ.bat` — программные сценарии.

Ветка не содержит полноценного портативного Python, всех обучающих данных и дополнительных весов авторазметки. Некоторые видео в старой сборке являются указателями Git LFS: скачайте исходники через Git LFS либо выберите собственное видео. `02_Реализация/panoptr/finale_examples/rail_fallback.avi` — отдельный пример рельсового видео, не видео с БПЛА. Программа не подменяет пользовательские видеофайлы.

Проверка импорта и моделирование не подтверждают натурную работу на ВСМ, качество обнаружения, совместимость с промышленными камерами или работу на другом компьютере. Нужны отдельные испытания. Технические ограничения и лицензии компонентов сохраняются в документации проекта.
