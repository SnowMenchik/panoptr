# Симулятор ВСМ

Симулятор запускается отдельным процессом и не использует состояние потоков камер. Он загружает записанное видео, применяет сценарий ВСМ, выполняет YOLO inference и сохраняет обработанное видео, JSON и CSV.

Поддержано: 300/350/400 км/ч относительно скорости исходного видео, размытие, вибрация, яркость, дождь/снег/туман, пропуски кадров, отключение камеры, потеря GNSS, управляемая CPU/GPU-нагрузка. GPU-инжектор ограничен 50% duty и автоматически делает паузу при 82 °C.

## Метрики качества

Для `пропущено известных дефектов` и `ложные тревоги` нужна эталонная разметка известных дефектов (обычные исправные объекты в неё добавлять не нужно). Формат показан в `ground_truth_example.json`: номер исходного кадра, класс модели и абсолютный прямоугольник `x1,y1,x2,y2`. Сопоставление выполняется по классу и IoU >= 0.5. При имитации вибрации эталон автоматически преобразуется вместе с изображением.

Без эталона симулятор всё равно считает кадры, обнаружения, задержки, FPS, восстановление и ресурсы, но FN/FP показывает как `N/A`. Это принципиально: эти показатели нельзя достоверно вычислить только по предсказаниям самой модели.

## Изоляция

Процесс симулятора отдельный, однако физические CPU и GPU общие. Для чистого benchmark остановите живые камеры. Для проверки деградации всей системы их можно оставить запущенными. Для полной аппаратной изоляции выберите CPU или вторую видеокарту (поддержка явного номера GPU будет добавлена следующим этапом).
