# Лаборатория данных и моделей Panoptr

Модуль для неизвестного задания финала: проверить полученные данные, подготовить обучение, запустить базовую модель, сравнить результат и выгрузить предсказания. Открывается кнопкой **«Лаборатория данных»** в Panoptr или отдельным `../run_dataset_lab.bat`. Он работает в отдельном процессе; проверка данных не использует GPU. Текущие модели приложения автоматически не заменяются.

## Быстрый сценарий

Добавлена вкладка **4. Разметка**: 18 вариантов автоматических предложений и ручной редактор с подтверждением кадров. [Инструкция по моделям, проверкам и ограничениям](../../../10_Лаборатория_данных/README_Авторазметка.md). Экспорт разметки этой вкладки требует человеческого подтверждения; экспорт предсказаний вкладки 3 является исходным результатом модели.

1. Выберите формат, папку изображений и папку разметки. Для COCO выберите JSON.
2. Укажите классы в порядке целевых ID. Для семантики включите фон, например `background, rock`.
3. Для масок задайте явное соответствие: `{"0":0,"255":1}` означает источник 0 → фон, источник 255 → объект. `-1` означает игнорируемые пиксели. Для RGB ключ имеет вид `"255,0,0"`. Маски с палитрой PNG читаются по индексам палитры.
4. Задайте сцены через CSV или regex. Пары с одинаковым относительным именем находятся автоматически; суффикс `_mask` можно убрать полем настройки. При несовпадающих именах нужен CSV. Порядок файлов не считается соответствием.
5. Нажмите **«Проверить данные»**, изучите ошибки и наложения. Незнакомые значения масок показаны в отчёте; исправьте соответствие и проверьте снова.
6. Выберите новую выходную папку и нажмите **«Подготовить набор и BAT»**. Старые результаты не перезаписываются.
7. На вкладке обучения выполните проверку готовности, затем короткую пробу. Полное обучение запускайте отдельной кнопкой, когда ресурсы доступны.
8. Сравните две модели на val и экспортируйте предсказания. Перед сдачей сверяйте требуемые организаторами классы, имена файлов и кодировку результата.

Пример CSV, пути относительны выбранным входным папкам:

```csv
image,annotation,group
camera_a/frame_001.jpg,labels_a/mask_001.png,scene_01
camera_a/frame_002.jpg,labels_a/mask_002.png,scene_01
camera_b/frame_001.jpg,labels_b/mask_001.png,scene_02
```

Без CSV первая группа захвата regex задаёт сцену, например `^(scene\d+)_frame\d+$`. Вложенная папка также может обозначать сцену. Переключатель независимых изображений допустим только для действительно независимых снимков, не для соседних кадров или аугментаций. Для train/val нужны минимум две группы. Неправильно заданная сцена может привести к утечке; проверка имён и SHA256 не доказывает независимость съёмок.

## Поддерживаемые задачи

- **Семантическая сегментация**: индексные, серые и RGB-маски, 2–254 целевых класса. Исходный ignore преобразуется в 255. Изображение и маска обязаны иметь одинаковые размеры. Маски сохраняются PNG, а не конвертируются в прямоугольники. При обучении используется совместное масштабирование с сохранением пропорций; маска изменяется только nearest-neighbor, поля заполнены ignore.
- **Детекция**: YOLO bbox с пятью значениями и COCO bbox. COCO category_id явно переводятся в последовательные ID по сортировке исходных ID; названия должны соответствовать этому порядку. COCO RLE-маски сохраняются при экспорте разметки, но COCO-импорт обучения пока использует bbox; crowd/ignore требуют отдельного backend.
- **Instance-сегментация YOLO**: нормализованные полигоны, отдельный объект на строку, локальные веса YOLO segment. Проверка, подготовка, проба/обучение, сравнение и экспорт доступны. Bbox и полигоны не интерпретируются друг как друга.
- **Видео**: извлечение каждого 30-го кадра, до 300 кадров через интерфейс; шаг/предел доступны в CLI. Сохраняются исходные номера кадров, FPS и идентификатор видео. Разметка при извлечении не создаётся; все кадры одного видео относятся к одной группе.

Повреждённые файлы, неоднозначные пары, лишние аннотации, неизвестные классы, неверные bbox, EXIF-повороты и несовпадение размеров блокируют подготовку. Дубликаты с разной разметкой или разными сценами тоже блокируют её. Одинаковые изображения с одинаковой разметкой в одной сцене при подготовке сохраняются один раз. Проверяется наличие классов в обеих выборках перед обучением.

## Обучение и продолжение

Для семантики встроена небольшая U-Net. Без весов она обучается с нуля: это рабочий baseline для быстрого старта, а не заранее обученная модель РЖД. Для дообучения выбирайте семантический checkpoint этой лаборатории с теми же классами. YOLO .pt не подходит для этого backend.

Для детекции выберите локальные веса YOLO detect, для полигонов — YOLO segment. Автоматическая загрузка исходных весов отключена. Параметры задаются в интерфейсе и сохраняются в `training.json`. По умолчанию устройство CPU; для большой задачи выбирайте `cuda:0` после завершения текущих GPU-обучений. GPU-запуски лаборатории, включая оценку, используют общий файловый замок с подготовленными очередями 08/09. Замок защищает только программы, которые его соблюдают.

Проба работает на отдельном запуске: одна эпоха, до 16 кадров каждой выборки. Это проверка работоспособности, а не оценка качества. Основной запуск хранится в `runs/train`; пробные — в `runs/pilot_*`. `best.pt` выбирается по val, `last.pt` содержит состояние оптимизатора для продолжения. У семантики checkpoint фиксируется после полной эпохи; при принудительной остановке незавершённая эпоха будет повторена.

BAT в подготовленном наборе:

- `01_CHECK.bat` — целостность подготовленных файлов и настройки, без обучения/GPU-инференции;
- `02_PILOT.bat` — пробное обучение;
- `03_TRAIN.bat` — полное обучение;
- `04_RESUME.bat` — продолжение с last.pt.

Изменение датасета или настроек блокирует продолжение. Для нового эксперимента подготовьте новую выходную папку; можно указать best.pt предыдущего запуска для дообучения. Настройки также можно отредактировать в `training.json`. `PANOPTR_PYTHON` позволяет выбрать Python для BAT. Модуль не устанавливает пакеты автоматически; список зависимостей находится в `requirements.txt`. Для текущего компьютера предусмотрено использование уже имеющегося окружения обучения.

## Оценка и экспорт

Семантика оценивается попиксельно в исходном размере изображения: IoU, Dice и число эталонных пикселей по классам, mIoU и матрица ошибок. Ignore не участвует в оценке. Отсутствующий в эталоне и предсказании класс получает null, а не фиктивные 100%. Размер входа каждой сравниваемой семантической модели берётся из checkpoint и показан в отчёте. Детекция сравнивается на одинаковой val с imgsz=960.

Экспорт семантики: `masks/` с индексными PNG исходного размера, исходными относительными именами с расширением PNG, `classes.json`, CSV/JSON сопоставления, ZIP. Экспорт детекции: JSON с bbox в пикселях, уверенностью, ID классов и размерами кадров, ZIP. У YOLO segment в JSON также сохраняется точная маска каждого экземпляра как несжатая COCO RLE. Универсальная выгрузка не заменяет конкретный формат сдачи организаторам; обратное преобразование в исходные RGB-цвета или ID надо задавать под условия задания.

Val не является независимым тестом после подбора по нему модели. Отдельный внешний test и оценка времени/памяти в регламенте финала остаются необходимыми для обоснованных итоговых заявлений. Автоматическая смена модели в камерах Panoptr не выполняется.

## Репетиция

Кнопка **«Создать репетицию»** создаёт 12 искусственных изображений с масками в шести сценах. `good_config.json` пригоден для полного цикла. `broken_config.json` содержит потерянную маску, неправильный размер, неизвестный ID и дубликат с другой разметкой. Эти данные предназначены для проверки инструмента; метрики на них не характеризуют качество на железной дороге.

## CLI

```text
python cli.py audit --config input.json --output audit.json
python cli.py prepare --config input.json --output NEW_DATASET
python cli.py check --dataset NEW_DATASET
python cli.py pilot --dataset NEW_DATASET
python cli.py train --dataset NEW_DATASET
python cli.py resume --dataset NEW_DATASET
python cli.py compare --dataset NEW_DATASET --checkpoint first.pt --second second.pt --output comparison.json
python cli.py predict --checkpoint best.pt --images IMAGES --output NEW_EXPORT
python cli.py frames --video recording.mp4 --output NEW_FRAMES --every 30 --limit 300
python test_lab.py
```

Выходные данные интерфейса по умолчанию располагаются в `Panoptr_финал_2026-10-10/10_Лаборатория_данных`.
