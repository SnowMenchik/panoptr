# Работа с переносной сборкой на финале

Это полная папка Windows x64: свой Python, библиотеки, исходный код и локальные веса. Интернет, установленный Python и Codex для запуска не требуются. Распакуйте ZIP целиком в папку с правом записи; не запускайте программу внутри архива. Желательно Windows 10/11 x64, 16 ГБ RAM и более. GPU необязателен; для NVIDIA нужен совместимый драйвер. Оставьте место для своих видео, наборов и результатов обучения.

## Быстрая проверка

1. Запустите 05_Проверить_сборку.bat. Проверяются локальные зависимости, дочерний процесс и готовность основных моделей.
2. Для проверки контрольных сумм и инференса запустите в консоли из корня:

       runtime\python.exe -s -E start.py check --integrity --models

3. Запустите 06_Полигон_и_финал.bat. Выберите видео из examples или подключённую камеру, модель и устройство. Нажмите «Применить профиль», затем «Запустить канал». Съёмка сама не начинается. Для CPU начните с входа 640; большой вход может дать устаревшие результаты.
4. Если нужна обычная двухканальная демонстрация — 01_Запустить_CPU.bat или 02_Запустить_GPU.bat. Не запускайте параллельно несколько тяжёлых моделей и обучение перед показом.

## Что показать

- examples/rail.avi — известный кадр дефекта крепления; examples/drone.avi — известный кадр БПЛА. Выбирайте соответствующую задачу/модель. Это повторы снимков для проверки программы, а не независимый test.
- Карточка события, сохранённый кадр и контекст, решение оператора и запись обследования.
- «Карта рейсов» → «Демо двух рейсов»: новые/повторные наблюдения и подтверждение. Это вымышленная отдельная демонстрация; неизвестную координату не выдавайте за измеренную.
- 3D-стенд с колеёй 750 мм, сменой вставки, светом и повторяемыми сценариями. Его метки синтетические.
- Лаборатория → «Создать репетицию»: искусственные изображения/маски с правильными и намеренно ошибочными данными; аудит, подготовка, ручная коррекция и маленькая проба обучения.
- Серия испытаний с нормальными элементами, одной целью на опыт и ручной проверкой карточек; затем HTML/ZIP с доказательствами.

Галерея функций: screenshots/Галерея_функций.html. Пособие для защиты: PANOPTR_Пособие_для_защиты_2026-10-19.pdf. Оно описывает состояние 19 октября; дополнения режима полигона — в Финал_обновление_2026-10-31.md и в 02_Реализация/panoptr/finale_examples/README.md.

## Где менять код

- 02_Реализация/panoptr/main.py — главное окно, захват кадров, очередь инференса и каналы.
- finale.py / finale_ui.py — профили, протокол опытов и интерфейс финала.
- final_core.py / final_store.py / final_ui.py — события, доказательства и действия оператора.
- dataset_lab/ — импорт, аудит, подготовка, авторазметка, обучение и редактор.
- route_memory*.py / route_train_sender.py — история рейсов и очередь передачи.
- camera_design.py / virtual_stand.py / stand_geometry.py — расчёт камеры и виртуальный стенд.
- path_*.py — геометрия пути и сопровождение.
- trained_models.py и models/ — реестр доступных моделей и веса. Новые веса сохраняйте под новым именем, не заменяйте рабочие без сравнения.
- start.py — переносной запуск; runtime/ — готовые зависимости, не редактируйте их для изменения логики приложения.

Сначала сделайте резервную копию изменяемых .py. Их можно редактировать любым редактором UTF-8. Для запуска своего скрипта используйте runtime/python.exe; системный Python не требуется. Не обновляйте зависимости перед защитой. Если новое задание требует отсутствующей библиотеки, сначала проверьте её в отдельной копии сборки.

После изменений запустите 07_Тесты_после_доработок.bat. Это переносимый набор регрессии без исторических обучающих датасетов; журналы сохраняются в data/tests. Проверка API использует только 127.0.0.1. Тесты лаборатории создают временные искусственные данные и маленькие тестовые веса; производственное обучение не запускается. После ручной правки файлов проверка исходного manifest.json закономерно отметит изменения — не принимайте их автоматически за повреждение архива и не стирайте исходный manifest.

## Новые данные и обучение

Большие исторические датасеты и исходные скачанные архивы сюда не включены. Для нового задания используйте интерфейс лаборатории: сначала пары изображение–метка/маска, классы, фон, размеры и наложения; затем разделение по независимым группам/источникам и подготовка в новую папку. Подберите совместимые локальные веса detect/segment. Предложения авторазметки проверяются человеком. SAM 3 без отдельно доступных весов не входит в готовые режимы.

Обучение запускает участник после проверки данных. Храните исходные метки, параметры, seed, группировку и журналы; оставьте независимую контрольную серию. Не утверждайте улучшение по отдельным удачным кадрам. Каталог предыдущих запусков и метрики включены в 08_Обучение; рабочие подготовленные исторические датасеты переносятся отдельно, если команда планирует продолжать именно прежнее обучение.

Изменённый код проверяйте сначала на файле/синтетическом примере, затем на настоящем источнике. Реальные камеры, натурная точность, климат и работа оборудования на 400 км/ч требуют отдельных испытаний.
