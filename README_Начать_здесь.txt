PANOPTR — запуск в Windows x64

Инструкция установки и ограничения: README.md.
1. Установите Python 3.12 x64 с Python Launcher.
2. Запустите 00_Установить_среду.bat (требуется интернет).
3. Запустите 00_Скачать_модели.bat (требуется интернет).
4. Запустите 05_Проверить_сборку.bat и 01_Запустить_CPU.bat.

Виртуальная среда отдельная от системного Python. Если установка испорчена,
повторный запуск установщика создаёт новую среду, не удаляя старую.
